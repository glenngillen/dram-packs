# Save it: guide

Turn a request you keep typing into your own command or skill, then use it on real work.

> **Detection is not available yet.** Dram cannot recognize this pattern in your sessions today, so finishing this guide will not show a recognition. The guide is still worth doing: the saved command helps from the next request on.

## 1. Find a request you repeat

Ask your agent to help you look at your own recent work:

> Looking at the requests I have made in this project recently, which ones have I typed more than once in nearly the same words?

Or think of one yourself: a pull-request description, a release note, a "check this file against our conventions" request.

- If you already run a saved command for it, you already do this for that request. Pick another, or stop.
- If nothing repeats, **stop here**. There is no exercise to do and nothing to recognize; come back when you notice yourself retyping something.

## 2. Ask your agent to save it

Paste the request the way you usually write it and ask:

> Save this as a reusable command or skill in the place you actually read commands from. Keep my wording, and add the follow-up steps I usually ask for. Show me the file before saving.

If you are not sure where commands live for your agent, ask it to inspect its actual configuration rather than guessing a path. Built-in commands (such as a built-in `/review`) and plugin commands are useful, but they are not your own saved request.

## 3. Read it

Check that it says what you mean. Edit anything vague. Save it only when you are happy with it.

## 4. Take the step: run it yourself on the next real case

The next time the request comes up for real, **invoke the command yourself** instead of typing the request. Let it finish.

**Done:** you ran your own saved command or skill on real work and the run completed. Running it again on a different day is what makes it a habit.

**Not done yet:** if you only answered this guide's questions, saved a command but have not run it, or the agent invoked it without you choosing to, the pattern has not happened yet. That is fine. Nothing is recorded against you; the next step is to run it yourself next time.

## Later

Once several patterns happen on their own, keeping your saved commands where every project can reach them is the next step. That comes later; it does not replace noticing the repetition.
