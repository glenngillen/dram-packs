# Size it: guide

Break your largest real task into pieces that each fit one session, then finish the first piece on its own.

> **Detection is not available yet.** Dram cannot recognize this pattern in your sessions today, so finishing this guide will not show a recognition. The guide is still worth doing: a finished first step is worth more than a half-done whole.

## 1. Pick a real large task

Look at your own project's backlog for the largest piece of work you actually need to do: a migration, a multi-part feature, a refactor across many modules.

If everything you have right now is small (a one-line fix, a rename), **stop here**. There is no exercise and nothing to recognize; small tasks do not need sizing.

## 2. Ask for a breakdown

Ask your agent, before it changes anything:

> Break this into steps we can do one per session. For each step, say what "finished" means and how we will check it. Don't start any of them yet.

Read the list. Change it until each step is something you could finish and check in one sitting.

## 3. Take the step: do only the first piece

Start the first step on its own (in this session or a fresh one), and finish it.

**Done:** you broke the work into steps and the first step is finished. That is this pattern. Carry on with the next steps in later sessions; finishing every step is what turns this into a habit.

**Not done yet:** if you read the breakdown and then asked the agent to do everything at once, or you only discussed how you might split the work, the pattern has not happened yet. That is fine. Nothing is recorded against you; try again with your next large task.

## Later

Once several patterns happen on their own, you can save the way you break work down as a planning command or template you own, so large work starts from a plan every time. That comes later, not as a shortcut.
