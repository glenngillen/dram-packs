# Split it up: guide

When a real side task comes up in the middle of your work, hand it to a subagent and keep the main session on track.

> **Detection is not available yet.** Dram cannot recognize this pattern in your sessions today, so finishing this guide will not show a recognition. The guide is still worth doing: the main session keeps its focus.

## 1. Wait for a real side task

Work on a real task in your own project. Notice when something comes up that is not the main goal but has to be done: snapshots to update, a library to check, an unrelated failing test.

If no side task comes up, **stop here**. There is no exercise and nothing to recognize; come back when one does.

## 2. Take the step: hand it off

Ask your agent, for example:

> Use a subagent to update the snapshots, then tell me in two lines what changed. We'll carry on with the main task.

If you are not sure how your harness runs subagents, ask your agent what it actually supports before choosing.

**Done:** a subagent actually started on the side task because you asked. That is this pattern. When its short result comes back, carry on with the main task.

**Not done yet:** if the agent did the side task itself in the main session, or you only read this guide, the pattern has not happened yet. That is fine. Nothing is recorded against you; ask again the next time a side task appears.

## Later

Once several patterns happen on their own, you can define your own subagents for the side tasks you hand off most, and an instruction rule saying when to use them. That comes later, not as a shortcut.
