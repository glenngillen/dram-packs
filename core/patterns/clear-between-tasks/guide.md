# Clear between tasks: guide

Start your next unrelated task from a clean context instead of on top of the last one.

> **Detection is not available yet.** Dram cannot recognize this pattern in your sessions today, so finishing this guide will not show a recognition. The habit still helps from your next task switch on.

## 1. Wait for a real switch

This guide works on your own work, at the moment you are about to change task. You need:

- a session where you have already spent a fair amount of back-and-forth on one task (around six of your own prompts or more), and
- a next task that is **unrelated**: a different bug, feature or question, not the next step of the same one.

If you are still on the same task, or you have only exchanged a couple of prompts, **stop here**: there is nothing to clear yet. If you have no real task to switch to, stop too; there is no exercise and nothing to recognize.

## 2. Keep what the next task needs

Ask your agent:

> Is anything from this conversation needed for the next task? If so, summarize just that in a few lines.

Usually the answer is "nothing". If there is something, copy it.

## 3. Take the step: clear, then start the new task

Run `/clear` (or your agent's equivalent; if you are unsure, ask your agent which command resets its context in this tool). Then describe the new task, pasting the short summary only if you kept one.

Compacting the conversation, resuming an old session or just opening a new window is not the same step: compaction keeps a summary of the old task in context.

**Done:** you cleared after substantial work and your very next prompt started the unrelated task. That is what this pattern recognizes once detection is available.

**Not done yet:** if you read this guide and answered its questions but did not clear, or you cleared and carried on with the same task, the pattern has not happened yet. That is fine. Nothing is recorded against you; try it at your next real switch.

## Later

Once several patterns happen on their own, an instruction or saved command that keeps each session to one task can make this automatic. That comes later and does not replace clearing when you switch.
